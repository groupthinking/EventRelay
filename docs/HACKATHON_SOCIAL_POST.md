## LinkedIn Post:

I'm thrilled to submit EventRelay (UVAI) to the #AllThingsAgenticHackathon!

Technical knowledge is increasingly shared through video, yet converting video insights into production software remains a tedious, manual chore.

We built EventRelay to transform passive video content into an active, continuous enterprise workflow. 

🏗️ How it works:
1. Video Ingestion: Transcripts & keyframes are captured and scrubbed via Model Armor.
2. Multimodal Reasoning: Gemini 2.5 Pro & Gemma extract structured event graphs.
3. Autonomous Execution: Model Context Protocol (MCP) agents generate code, create GitHub pull requests, and manage cloud infrastructure.
4. Multimodal Synthesis: Google Veo generates 10s visual summaries, while Google Lyria creates podcast-ready audio executive briefs.
5. Observability: Full OpenTelemetry tracing on Google Cloud Run.

Check out our hosted app at https://uvai.io and explore our GitHub repository at https://github.com/groupthinking/EventRelay.
