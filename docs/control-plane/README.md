# Control plane

Single operational home for EventRelay/UVAI execution discipline.

```text
docs/control-plane/
  00-CEO-DIRECTIVE.md     binding rules
  README.md               this file
  inventory/              verified facts (LIVE-STATUS, SURFACES, DOC-REGISTRY, BRANCHES…)
  plans/                  EXECUTION-PLAN and future goal files
  sessions/               smoke outputs, pipeline JSON, change notes
  archives/               historical docs moved under GATE-6
```

Start: `00-CEO-DIRECTIVE.md` → `plans/EXECUTION-PLAN.md` → `inventory/LIVE-STATUS.md`.
