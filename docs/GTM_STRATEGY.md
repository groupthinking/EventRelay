# UVAI Go-To-Market Strategy

**Created**: January 24, 2026
**Based on**: Dogfooding analysis of AI design tool videos

---

## 🎯 Target Market Segments

### Primary: Developer-Designers (DevDes)

- **Size**: ~2.5M globally
- **Pain Points**:
  - Context switching between Figma and code
  - Recreating designs manually
  - Watching long tutorial videos
- **Willingness to Pay**: High ($29-99/mo)
- **Acquisition Channels**: GitHub, ProductHunt, Twitter/X

### Secondary: Remote-First Product Teams

- **Size**: ~500K teams
- **Pain Points**:
  - Too many recorded meetings
  - No time to watch
  - Action items get lost
- **Willingness to Pay**: High ($99-499/mo per team)
- **Acquisition Channels**: LinkedIn, Slack communities

### Tertiary: Content Creators/Educators

- **Size**: ~1M professional creators
- **Pain Points**:
  - Repurposing video content
  - Creating written summaries
  - Extracting clips/highlights
- **Willingness to Pay**: Medium ($19-49/mo)
- **Acquisition Channels**: YouTube, Twitter/X

## 💰 Pricing Strategy

### Free Tier

- 5 videos/month
- Max 10 min videos
- Basic summary + actions
- No API access

### Pro ($29/month)

- 50 videos/month
- Max 60 min videos
- Full analysis suite
- API access (100 calls/day)
- Export to JSON/Markdown

### Team ($99/month - per 5 seats)

- 500 videos/month
- Unlimited video length
- Shared workspace
- Team analytics
- Slack/Teams integration
- API access (1000 calls/day)

### Enterprise (Custom)

- Unlimited everything
- On-premise option
- Custom integrations
- SLA guarantee
- Dedicated support
